# 🌌 Alien Soil Doctor (ISRU Project)

**Alien Soil Doctor** is an AI-powered project designed to evaluate alien soil habitability using Earth soil data extended with extraterrestrial factors such as **radiation levels, alien chemical index, and toxic compound risks**.  
This project is part of an **In-Situ Resource Utilization (ISRU)** research initiative and leverages **Reinforcement Learning (RL)** for continual self-improvement.

---

## 🚀 Features
- ✅ Dataset preprocessing & normalization  
- ✅ Alien soil generator for simulations  
- ✅ Hybrid Classification + Reinforcement Learning model  
- ✅ Continual learning (self-improvement over time)  
- ✅ Model evaluation with explainability & accuracy reports
