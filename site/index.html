How it works

  1. Missing feature columns are auto-filled with 0.0 and depth ranges such as "0-100cm" become numbers.
  2. Features are standardized across the uploaded batch, matching the original StandardScaler step. Upload at least a few samples.
  3. The trained Keras dueling DQN (15 → 128 → 128 → value + advantage heads) runs with its original weights. The class with the highest Q-value wins, and that Q-value is reported as confidence.
  4. Samples that aren't habitable get rule-based suggestions for pH, nitrogen, alien toxicity, radiation and organic carbon.
  5. If your CSV includes a habitat column, a classification report is shown for the full set and for samples with confidence ≥ 0.95.
